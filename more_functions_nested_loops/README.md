# C - More functions, more nested loops

## Description
This project focuses on developing a deeper understanding of C programming through functions, nested loops, and conditional statements.

## Tools and functions learned
Nested loops, funcions, prototypes

## Tasks
| **Task name** | **Description** | **Key concept** |
| ------------- | --------------- | --------------- |
| `0-isupper.c` | Checks whether a character is uppercase. | ASCII values, conditional statements |
| `1-isdigit.c` | Checks whether a character is a digit from 0 to 9. | ASCII values, logical operators |
| `2-mul.c` | Multiplies two integers and returns the result. | Functions, multiplication, return values |
| `3-print_numbers.c` | Prints numbers from 0 to 9. | Loops, `_putchar`, ASCII conversion |
| `4-print_most_numbers.c` | Prints numbers from 0 to 9, excluding 2 and 4. | Loops, conditional statements |
| `5-more_numbers.c` | Prints numbers from 0 to 14, ten times. | Nested loops, integer-to-character conversion |
| `6-print_line.c` | Draws a straight line using underscores. | Loops, function parameters |
| `7-print_diagonal.c` | Draws a diagonal line using backslashes. | Loops, spacing, escape sequences |
| `8-print_square.c` | Prints a square using hash characters. | Nested loops, rows and columns |
| `9-fizz_buzz.c` | Prints Fizz, Buzz or FizzBuzz for multiples of 3 and 5. | Modulo operator, conditional logic |
| `10-print_triangle.c` | Prints a right-aligned triangle using hash characters. | Nested loops, spacing, patterns |
