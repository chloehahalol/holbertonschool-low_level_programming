# Project 1 - Hello World

## Description

This project introduces the fundamentals of C programming, including writing, 
compling and executing C programs using gcc. 

This project also introduces Betty coding style to ensure consistent formatting,
and documentation standards. 

## Commands learned
` gcc`
`printf(3)`
`puts`
`putchat`

## Tasks 

A table of the exercises completed. 

| Task name | Description |
| --- | --- |
| 0. Preprocessor | Runs a C file through the preprocessor and saves it into another file. |
| 1. Compiler | Compiles a C file but does not link. |
| 2. Assembler | Generates the assembly code of C and saves it in an output file. |
| 3. Name | Compiles a C file and creates an executable |
| 4. Hello, puts | Prints a text followed by a new line, returns 0 |
| 5. Hello, printf | Prints a text using `print r` followed by a new line, returns 0 |
| 6. Size if not granduer | Prints the size of various types on a computer |
