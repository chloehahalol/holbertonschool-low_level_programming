# Project 1 - Hello World 👋

## Description ✏️

This project introduces the fundamentals of C programming, including writing, 
compling and executing C programs using gcc. 

This project also introduces the Betty coding style to encourage consistent formatting
and documentation standards. 

## Tools and functions learned ⚒️
`gcc`
`printf()`
`puts`
`putchar`

## Tasks ✅

A table of the exercises completed. 

| Task name | Description | Key concept |
| --- | --- | --- |
| 0. Preprocessor | Runs a C file through the preprocessor and saves it into another file. | gcc -e, preprocessing |
| 1. Compiler | Compiles a C file but does not link. | gcc -c, object files |
| 2. Assembler | Generates the assembly code of C and saves it in an output file. | gcc -s, assembly code |
| 3. Name | Compiles a C file and creates an executable | gcc -o, executables |
| 4. Hello, puts | Prints a text followed by a new line, returns 0 | `puts()` escape characters |
| 5. Hello, printf | Prints a text using `print r` followed by a new line, returns 0 | `printf()`, newline characters |
| 6. Size if not granduer | Prints the size of various types on a computer | `sizeof`, data types, architecture |
