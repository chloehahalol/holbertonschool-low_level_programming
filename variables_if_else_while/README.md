# C - Variables, if, else, while ⚖️

## Description ✏️

This project focuses on understanding how to write conditional statements by:
- Declaring and initialising variables.
- Repeating operations using loops.
- Printing output using `putchat()` and `printf()`. 
- Writing code according to Betty coding style and ANSI C89 coding standards. 

## Tools and functions learned ⚒️
`if` `if ... else` `putchar()` `printf()`

## Tasks ✅
| File | Description | Key concept |
| --- | --- | --- |
| `0-positive_or_negative.c` | Determines whether a randomly generated integer is positive, negative, or zero. | Variables, `if`, `else if`, `else` |
| `1-last_digit.c` | Determines whether the last digit of a random integer is greater than 5, equal to 0, or less than 6 and not 0. | Modulo `%`, conditional statements |
