# C - Functions, nested loops ➰

## Description ✏️
This project introduces functions and nested loops in C programming, focusing on breaking problems into smaller, reusable pieces of code.

## Tools and functions learned ⚒️
Nested loops, functions, prototypes, variables

## Tasks ✅
| **Task name** | **Description** | **Key concept** |
| ------------- | --------------- | --------------- |
| `0-putchar.c` | Prints `_putchar` followed by a new line. | `_putchar`, character output |
| `1-alphabet.c` | Prints the lowercase alphabet. | Functions, loops, ASCII |
| `2-print_alphabet_x10.c` | Prints the lowercase alphabet ten times. | Nested loops |
| `3-islower.c` | Checks whether a character is lowercase. | ASCII, conditional statements |
| `4-isalpha.c` | Checks whether a character is a letter. | Logical operators, ASCII |
| `5-sign.c` | Prints and returns the sign of a number. | Conditional statements, return values |
| `6-abs.c` | Calculates the absolute value of an integer. | Arithmetic, conditional statements |
| `7-print_last_digit.c` | Prints and returns the last digit of a number. | Modulo operator, integer arithmetic |
| `8-24_hours.c` | Prints every minute of a 24-hour day. | Nested loops, time formatting |
| `9-times_table.c` | Prints the 9 times table. | Nested loops, multiplication, formatting |
| `10-add.c` | Adds two integers and returns their sum. | Functions, parameters, return values |
| `11-print_to_98.c` | Prints integers from a starting number to 98. | While loops, increment, decrement |
